# BarnCRM feature catalog

BarnCRM is a free, open source suite of Salesforce packages: a neutral Core for any organization, plus optional modules for giving, integrations, volunteers, programs and grants. This catalog lists what each package does, grouped by module and category, Major features first, with the status of each item as of 2026-10-25 (main at 24a4298b).

**How this is kept current:** the catalog is updated in the same pull request that adds, changes, or removes a feature. A branch that builds a feature sets its row to "Built, not merged" with the branch name; the merge makes it "Shipped".

**Legend**

- **Major**: a headline capability a buyer or admin would name.
- **Minor**: a supporting capability, setting, or refinement.
- **Shipped**: merged to main. No package version has been created yet (the namespace is deferred), so "Shipped" means built and on main, not yet installable as a released package.
- **Built, not merged**: built on the named branch or open pull request, waiting for review, an org test run, or the branches it is stacked on.
- **Replaced**: shipped earlier and superseded by the feature the row names; kept in the code only where the row says.
- **Planned**: in the product plan roadmap (iteration shown where the plan gives one). "Proposed" marks an idea recorded for consideration, not approved or scheduled.
- **Feature ID**: the product plan ID (C = Core, G = Giving, X = Mirror, V = Volunteers, P = Programs, L = Logic Models, F = Grants, CH = Corporate Hub, PB = Portal Builder, LB = LWC Builder, SG = Scholarships and Outbound Grants, EV = Event Management, PM = Project Management), or an ADR where the capability came from a decision rather than a numbered feature. "new ADR" is a decision record still on its branch; it gets a number when it merges.

**Editions**

| Edition | What it is | Packages |
|---|---|---|
| Standard Edition | For any other Salesforce org: businesses, clubs and any organization that is not a nonprofit. Includes the full core suite of tools | Core, with Contact Point Sync and Project Management offered as modules (Event Management, Corporate Hub, Portal Builder, Territory Management and LWC Builder later); no nonprofit module is shown or offered |
| Nonprofit Edition | For nonprofits; a choice any organization can make. The full core suite of tools plus the nonprofit tools | Core plus Giving, with Mirror, Volunteers, Programs, Logic Models, Grants, Scholarships and Outbound Grants and Project Management offered as further modules (Event Management, Corporate Hub, Portal Builder, Territory Management and LWC Builder later, in both editions) |

BarnCRM is one suite of tools in two editions, and both editions include the full core suite of tools; the Nonprofit Edition adds the nonprofit tools (Giving and the other nonprofit modules). An admin installs Core, then chooses the edition once in the first-run setup window (the Setup Assistant's first step shows that answer); the Nonprofit Edition opens Salesforce's installer for Giving, and other modules are offered the same way. The Standard Edition shows no nonprofit module anywhere in Core; one already installed keeps working. A module that is never installed leaves nothing in the org. Changing the edition later: [editions.md](admin-guide/editions.md).

## 1. Core

**Edition:** both. Core is neutral: households, relationships, addresses, import, rollups, settings, Health Check and the Setup Assistant carry no nonprofit wording (C-29, merged in PR #163). The BarnCRM names landed in PR #181. Core installed alone is the Standard Edition.

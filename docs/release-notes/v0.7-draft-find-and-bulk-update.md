# v0.7 draft release notes: Find and bulk update

Draft lines for the v0.7 release notes, written for Maria (plan Section 7.5). Features C-34 and
C-35, in Core.

- **Find the records you need, from any kind of record you can see.** The new **Find** tab
  lists exactly the records you ask for: choose the columns (including columns of a related
  record, such as a person's organization), filters (with periods such as "this year" or "the
  last 30 days"), the order and a row limit. The query it runs is shown, read only, for anyone
  who wants to check it. See [Find and export records](../admin-guide/find.md).
- **Save a question and share it.** A saved query is yours alone unless you share it; a
  colleague who opens a shared query sees only the records their own access allows.
- **Export to CSV.** Download the results as a CSV file that Excel opens cleanly, up to the
  export row limit in BarnCRM Settings, Import (50,000 rows unless you change it). A value that
  starts like a spreadsheet formula is written as text, so opening the file never runs one.
- **A permission of its own.** Find is part of the BarnCRM Admin role, and the new BarnCRM Find
  and Export permission set lets somebody else find and export without changing anything. It
  gives no access to any record.
- **Change many records at once, and take it back.** The new **Bulk Update** tab changes up
  to five fields on every record a Find query returns: set a value, clear it, or copy another
  field of the same record. You see how many records match and how the first few would change,
  and you type that number to confirm. If more records match by the time you confirm, nothing
  is changed. See [Bulk update](../admin-guide/bulk-update.md).
- **Your own access, and your organization's rules.** A bulk update changes only records and
  fields you may edit, and your validation rules, duplicate rules and automation run as on any
  save. A record that is refused is listed with the reason; the rest still save.
- **Undo.** For as long as an import can be undone (30 days unless you change it), a bulk
  update can be undone too: each value goes back, except one somebody has changed since.
- **What BarnCRM keeps itself stays safe.** Rollup totals, household names and greetings,
  formula and system fields, and BarnCRM's own records (imports, the journal, the error log,
  settings, receipts) cannot be bulk updated. A rollup you add later is protected at once.
- **Data Jobs.** Imports and bulk updates are now listed together on the new **Data Jobs**
  tab. The most records one bulk update may change is a new setting in BarnCRM Settings,
  Import (50,000 unless you change it), and the new BarnCRM Bulk Update permission set lets
  somebody bulk update without being an administrator.

# v0.6 draft release notes: inbound gift API and accounting export

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Features X-03,
X-04 and X-06, in the Connect module.

- **Gifts can arrive by themselves.** Your online giving page, payment processor or
  integration tool can now record gifts in Open Impact directly, through a web address or
  the new **Record Inbound Gift** action in Flow. Each one becomes an ordinary gift, with its
  household, its fund and its place in the totals.
- **Sending twice records once.** Every gift carries its identifier from the sending
  system. A gift sent again is recognized and not recorded a second time, and the same
  identifier with a different amount is refused rather than guessed at.
- **Nobody is invented.** A gift for a donor Open Impact cannot find is refused and noted in
  the Error Log, so a new supporter is added once, properly, rather than as a duplicate.
- **The month's gifts, ready for the books.** A new **Accounting Export** page downloads the
  gifts in any date range as a spreadsheet file: one row per fund, with the fund's accounting
  code, refunds as negative rows on the day the money went back, and columns that never
  change, so your QuickBooks or Xero import is set up once.
- **For developers:** the API reference and sample requests and responses are in
  `docs/api/`.

# v0.5 draft release notes: import engine fixes

Draft lines for the v0.5 release notes, written for Maria rather than for developers
(plan Section 7.5). An independent review of the import engine found these; each is fixed.

- **A column you cannot edit is no longer dropped without a word.** When your user may not
  edit a field a column is mapped to, the column is skipped, as before, and the run log now
  says so once for each such field, in the dry run and in the commit: "Not loaded: you do not
  have access to" the field. Before, the values vanished silently, so a migration file's
  Email Opt Out and Do Not Call columns could appear loaded when they were not.
- **The Nonprofit Admin role can import consent and contact details.** It now grants edit
  access to Email Opt Out, Fax Opt Out, Do Not Call, Email, the phone numbers, the mailing
  address, Title and Birthdate on contacts, the fields import mappings use for people. Where people are
  person accounts, the matching person fields follow the same access.

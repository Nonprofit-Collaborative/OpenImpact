# v0.1 release note lines (draft)

These are the release note lines each v0.1 feature writes as part of its definition of
done (plan Section 7.4). They are written for Maria, not for developers. The finished
public release note is assembled from this file when v0.1 is promoted, and the internal
iteration report is written separately in `v0.1.md` (see the README in this folder).

Each feature appends its own lines here. Do not rewrite another feature's line.

- **Pause automation when you need to (C-04).** Nonprofit Settings now has an Automation
  page listing everything Open Impact does for you in the background, each with a switch
  and a description in plain language. One button pauses all of it for one, two, four,
  eight, or twenty four hours while you load a spreadsheet, and it turns itself back on
  when the time is up. A banner on the home page shows when a pause is in effect, and every
  change is recorded with who made it and when.
- **See what went wrong, in words you can use (C-05).** When something fails inside Open
  Impact, it is now written to an Error Log you can read in the app instead of disappearing
  into a technical log. The home page shows how many new errors are waiting and the five
  most recent, and you can mark each one acknowledged or resolved as you work through them.
  Every entry says what happened and what to do about it, with the technical detail kept
  separately for a support request.

# v0.5 draft release notes: Health Check v2, with fix actions (C-21)

Written for Maria, to be folded into `v0.5.md` at the end of the iteration (plan Sections 7.4
and 7.5).

- **Health Check can now put things right, not only report them.** Six findings have a button
  that does the work: use the coexistence mode your org needs, switch household membership to
  the junction, add the packaged rollups your org is missing, add the missing automation
  switches, add the missing import templates, and finish handing out the Nonprofit Admin role.
- **Every fix tells you what it is about to do, before it does it.** Pressing a fix button
  changes nothing. It shows you what would happen, counted from your org: how many records,
  and their names. You confirm, or you cancel. Afterwards it says what it actually did, and the
  report is re-run underneath it so you can watch the finding go.
- **No fix deletes anything.** Not a record, not a row, not ever, whatever the finding says. If
  the only way to clear something is to delete it, Health Check reports it and leaves the
  decision with you. The rule that decides which findings may have a button at all is written
  down as ADR-0029, and a new fix has to pass its six conditions in review.
- **Pressing a fix twice is the same as pressing it once.** Before a fix acts it looks at your
  org again, and if there is nothing left to do it says so and changes nothing. A stale browser
  tab, a second click, or two administrators working at the same time all end the same way.
- **A fix that fails leaves nothing half done.** Anything it had already written is undone, the
  details go to the Error Log, and the page tells you in a sentence rather than failing quietly.
- **Four new things Health Check looks for.** Rollups, automation switches and import templates
  that this package ships but your org never created, which happens when nobody has opened the
  page that would have created them; and people who hold the Nonprofit Admin permission set
  without the role that carries it, which is how an org whose install was interrupted ends up
  looking as though it has no administrator at all.
- **One new finding deliberately has no button.** Automation rows left behind by an upgrade that
  no longer ships them are reported and left alone. Nothing runs them, they change nothing, and
  removing them would mean a delete.
- **Nothing about your data changed.** C-21 adds no object, no field and no rollup. Every fix
  writes configuration this package owns and calls a service that already existed and was
  already safe to run twice.

Read [the admin guide page](../admin-guide/health-check.md) for the walkthrough, including what
each of the six buttons shows you before it acts.

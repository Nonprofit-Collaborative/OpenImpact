# v0.5 draft release notes: Health Check v2

Draft lines for the v0.5 release notes, written for Maria (plan Section 7.5). Feature C-21.

- **Health Check fixes more for you.** Four new findings with a fix button: totals Open Impact
  ships that are missing, automation switches that are missing, import templates that are
  missing, and nightly totals that are not scheduled.
- **Every fix asks first.** A fix button shows what it will do, counted from your org, and
  waits for Confirm. The three fixes that already existed now ask first too.
- **Fixes only add.** No fix deletes anything or changes a value you chose, pressing one twice
  does nothing more, and each can be undone on its own page.
- **Every automation has its switch from the start.** Installing or upgrading a package now
  creates the Automation page switch for every automation it ships. Before, the page could be
  empty until somebody restored the switches.
- **Restored totals never fight your own.** A shipped total whose field one of your own active
  totals already writes is not restored, and Health Check says which one it left out.
- **Fixes are recorded.** Every fix that runs appears under Recent changes in Nonprofit
  Settings with what it created.
- **Nothing to install or configure.** No object, field or setting was added.

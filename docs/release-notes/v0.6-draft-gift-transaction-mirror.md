# v0.6 draft release notes: Gift Transaction mirror

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Feature X-07, in
the Connect module, for organizations on Nonprofit Cloud (Agentforce Nonprofit).

- **Your gifts in Nonprofit Cloud's donor summaries.** Choose **Gifts to Gift Transactions** in
  BarnCRM Settings and every received gift gets a matching Gift Transaction, so donor pages,
  giving levels, actionable lists and Agentforce see the gifts you enter in BarnCRM. Choose
  **Gift Transactions to Gifts** instead while gifts still arrive in Nonprofit Cloud, and each
  paid Gift Transaction becomes a gift.
- **Nothing moves until you say where to start.** You name the status your paid Gift
  Transactions have and a start date, so the gifts you loaded from Nonprofit Cloud are never
  copied back a second time.
- **One direction at a time, every night,** with Run now for when you cannot wait. Off until you
  choose, and invisible in an org without Nonprofit Cloud.
- **See where they disagree.** The Gift Transaction mirror page compares gifts and paid Gift
  Transactions for any date range and lists every difference.
- **Not yet:** refunds, designations, campaigns and soft credits are not mirrored. A refund
  recorded in BarnCRM still needs recording in Nonprofit Cloud if its totals must show it.

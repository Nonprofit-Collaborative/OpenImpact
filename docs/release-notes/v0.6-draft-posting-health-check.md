# v0.6 draft release notes: Health Check for unposted gifts in a closed period

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). A follow-up to
G-20 (posting and closed periods), in the Giving module, recorded as future work in ADR-0053.

- **Health Check now catches a closed month that was never exported.** If any gift falls on or
  before your Books Closed Through date but was never marked posted to accounting, Health
  Check names how many, links a few of them, and tells you what to do: mark them posted from
  the Accounting Export page (Connect) once they are genuinely in a file you exported, or move
  Books Closed Through back to reopen the period, which needs no add-on package.
- This is a detection finding, the same shape as the other Health Check findings that count and
  link records: it does not change anything by itself.

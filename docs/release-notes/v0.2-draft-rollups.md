# v0.2 draft release note lines: rollups

Feature-level release note lines for v0.2, written for Maria as each rollup feature meets its
definition of done (plan Section 7.4 and Section 7.5 item 7). They are collected here during the
iteration and assembled into the public release notes when v0.2 is promoted. This file is a
holding place, not the release notes themselves.

## C-13: vendored rollup engine

- Your totals (household giving, contact giving, fund and appeal totals) are now calculated by a
  proven open source rollup engine rather than one written from scratch, and every total shows the
  time it was last calculated, so you can always tell whether a number is current.

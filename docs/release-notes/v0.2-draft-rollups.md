# v0.2 draft release note lines: rollups

Feature-level release note lines for v0.2, written for Maria as each rollup feature meets its
definition of done (plan Section 7.4 and Section 7.5 item 7). They are collected here during the
iteration and assembled into the public release notes when v0.2 is promoted. This file is a
holding place, not the release notes themselves.

## C-13: vendored rollup engine

- Your totals (household giving, contact giving, fund and appeal totals) are now calculated by a
  proven open source rollup engine rather than one written from scratch, and every total shows the
  time it was last calculated, so you can always tell whether a number is current.

## C-13: the rollup adapter and the Rollups page

- **One place to see every total Open Impact keeps for you.** Nonprofit Settings has a new
  **Rollups** page listing every total, what it counts, where it shows, when it was last
  calculated, and whether it is recalculated as records are saved, nightly, or both.
- **A total is never a mystery.** Every rollup carries its own last calculated time on the
  Rollups page, and every record carries a **Rollups last calculated** field, so "is this number
  current" has an answer in both places. If nothing has run in 36 hours, the Hub says so.
- **You decide when each total is recalculated.** Real time keeps a number right the moment a
  record is saved, Scheduled recalculates it in the nightly run, and Both does the first and
  reconciles with the second. A new rollup starts in whichever of the three you set as the
  default.
- **Recalculate one total, or all of them, without leaving the page.** A Recalculate button on
  each row runs that total now; Recalculate all runs the nightly work immediately.
- **The nightly run is started and stopped from the app.** No Salesforce Setup, no scheduled job
  to find: one button on the Rollups page schedules it for 2:00 AM and another stops it.
- **Fiscal years are yours, not the calendar's.** Set the month your fiscal year starts and every
  "this year", "last year", and "two years ago" total follows it at the next recalculation.
- **Turning a rollup off never deletes what it calculated.** An inactive rollup stops being
  recalculated and the numbers already on your records stay exactly as they are.

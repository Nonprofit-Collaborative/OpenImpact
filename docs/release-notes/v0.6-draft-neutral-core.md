# v0.6 draft release notes: BarnCRM Core on its own, for any organization

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Feature C-29,
ADR-0059: Core is neutral, and everything about gifts and receipts comes with Giving.

- **New names for the everyday places.** The product is now called **BarnCRM**. The Nonprofit
  Hub app is now called **BarnCRM**, and Nonprofit Settings is now **BarnCRM Settings**. The
  Nonprofit Admin, Staff, Read Only and Duplicate Review permission sets and the Manage
  Nonprofit Settings permission are renamed the same way, and so are their API names
  (`Barn_Settings__c`, `Manage_Barn_Settings`, `Barn_Admin`, `Barn_Staff`, `Barn_Read_Only`,
  `Barn_Duplicate_Review`, `Barn_Admin_Group`, the `Barn_Hub` app and the `Barn_Hub_Home` and
  `Barn_Settings` tabs). Nothing moved: the same tabs, pages, sections and settings, with new
  names. Anything you built that names the old API names (a report, a flow, a permission set
  assignment script) needs the new ones.
- **One app, two suites.** Nonprofits and other organizations use the same BarnCRM app. The
  Nonprofit Suite adds Giving and the nonprofit modules; the Community Suite is Core with the
  modules that fit.
- **Organizations that are not nonprofits can use BarnCRM Core on its own.** Without the
  Giving module, Core now says nothing about gifts, donors or receipts: the Setup Assistant has
  seven steps, the organization step asks only for your legal name and address, and Health
  Check asks no receipt questions.
- **With Giving installed, the steps and settings are where they were.** The Setup Assistant
  still has eight steps in the same order: Giving adds the default fund and appeal step, the
  tax identification number, logo, signature and signer on the organization step, and the
  first gift check. Your receipt settings are in the same Organization section of BarnCRM
  Settings, and Health Check still reports failed receipts and anyone holding Override Receipt
  Lock.
- **Some wording changes even with Giving installed**, because Core's own text is the same for
  every organization:
  - the app, BarnCRM Settings, the Manage BarnCRM Settings permission and the BarnCRM permission sets have their new names;
  - the **Generic donor list** import template is now the **Generic contact list**;
  - Health Check, household merge and other Core messages speak of records, contacts and
    totals rather than gifts and donors.
  The import wizard's gift columns, control total and donation matching keep their wording.
- **Fundraising Staff comes with Giving.** The role is listed on the Access page when Giving is
  installed, as before.

# v0.1 release note lines: coexistence mode and Health Check

Draft lines for features C-07 and C-11, written for Maria and collected into the public v0.1
release notes when the iteration closes (plan Section 7.5 item 7). The iteration report
itself is `v0.1.md`, written at the end of v0.1.

## What is new

- **Open Impact now recognizes your org.** The first time you open Health Check or the Setup
  Assistant, it looks at what is already installed: Person Accounts, Nonprofit Cloud objects,
  the Nonprofit Success Pack, standard Sales and Service Cloud objects. It tells you what it
  found, in those words, and recommends the coexistence mode that fits.
- **Coexistence mode is one setting, in the app.** Standalone, NPSP coexistence, or Agentforce
  Nonprofit coexistence. Confirm the recommendation with one button, or pick another mode in
  Nonprofit Settings under General. You can change it later, and every change is recorded with
  who made it and when.
- **Choosing Agentforce Nonprofit coexistence sets up households correctly.** In a Person
  Accounts org, household membership moves to the membership records that Person Accounts
  need, in the same save, so you never have to know that the two settings go together.
- **Health Check tells you what to fix, and takes you there.** It reports your org shape, a
  coexistence mode that does not match what is installed, household membership that will not
  work with Person Accounts, an org running more than one currency, nobody assigned the
  Nonprofit Admin role, active users who cannot see the app, automation left paused, and
  errors nobody has read. Every finding says what to do about it, and most of them have a
  button that does it or opens the right page.
- **Health Check is readable by everyone.** You need the Manage Nonprofit Settings permission
  to act on a finding, but anyone who can open the Nonprofit Hub can read the report and tell
  an administrator what it says.

## Known limits in this version

- Shield Platform Encryption cannot be detected from inside the app. Health Check says so
  rather than guessing. If your org uses it, say so before you load data.
- Multi-currency orgs are detected and reported, but currency conversion is not supported in
  v1. Totals add up amounts as they were entered.
- The Gift Transaction mirror for Nonprofit Cloud orgs arrives with the Connect module in
  v0.6. Until then Health Check mentions it once, as information, and nothing is broken.

## For the record

- Detection is done through describe calls against names held in String constants, so Core
  still installs and runs on an org with only Platform licenses (ADR-0009, ADR-0013).
- `scripts/ci/check-standard-objects.sh` gained a `// detection-only:` marker for exactly
  those constants, and prints every exempted line on each run. See the contributor guide,
  "Detection-only exemptions".

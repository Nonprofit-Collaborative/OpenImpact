# v0.5 draft release notes: duplicates

Draft lines for the v0.5 release notes, written for Maria (plan Section 7.5). Feature C-20.

- **Find the people and households you have twice.** A new **Duplicates** panel on the
  Households page of Nonprofit Settings scans the records you already have with Salesforce's
  own duplicate rules and lists every pair it finds, including the ones imported before
  anybody was checking.
- **Merge two households in one step.** Each household pair has **Merge households**, which
  uses the same merge as the household record page: members move, totals recalculate, and
  the name is worked out again.
- **Merge two people with Salesforce's own merge.** The person record page now shows the
  Potential Duplicates card, where Salesforce's compare and merge starts.
- **Say "not a duplicate" once.** A pair you dismiss, with a reason, is not suggested again.
- **Nothing to set up in most orgs.** Open Impact uses the duplicate rules Salesforce
  switches on in every new org. One object is added, Duplicate Dismissal.

# v0.6 draft release notes: posting and closed periods

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Feature G-20, in
the Giving module, with its button on Connect's Accounting Export page.

- **Gifts in the books stay the way the books hold them.** After downloading the accounting
  export, your bookkeeper clicks **Mark these gifts posted**. A posted gift's date, amount,
  donor, payment method, reference and funds can no longer change, and it cannot be deleted.
  The gift page shows when it was posted and by whom.
- **Close a month.** In **Nonprofit Settings**, **Giving**, **Accounting periods**, set the date
  the books are closed through. No gift dated on or before it can be added, changed in those
  ways, or deleted.
- **Refunds still work.** A refund or write-off of a posted gift is recorded as usual, as a new
  gift dated today, so it lands in the month the money went back.
- **Late gifts are not missed.** The accounting export can now show only gifts not yet posted,
  so a gift entered late into a month you already exported turns up in the next file.
- **Your acknowledgments, receipts and soft credits carry on** as before: only the values the
  books hold are locked.
- **Pausing automation does not lift the lock.** Reopening a closed month or changing a locked
  gift is done by an administrator with a permission granted in Setup, and every use is written
  to the Error Log.

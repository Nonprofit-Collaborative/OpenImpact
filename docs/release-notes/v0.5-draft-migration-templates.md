# v0.5 draft release notes: migration import templates

Draft lines for the v0.5 release notes, written for Maria (plan Section 7.5). Plan Section 6.3,
"NPC import templates", and the NPSP templates moved to v0.5.

- **Load your Nonprofit Cloud exports as they are.** Four new import mappings read Nonprofit
  Cloud's own exports without renaming a column: person accounts, gifts from people with their
  designations, gifts from organizations, and gifts with no designation. The gift's record ID
  becomes its external ID, so loading a file twice creates each gift once. See "Migrating from
  Nonprofit Cloud" in the admin guide for the export queries and the order to load them in.
- **Load your NPSP exports as they are.** Three more mappings read NPSP's exports: contacts
  with their home, work and alternate email and which one they prefer, and paid payments from
  people and from organizations, each with its opportunity's campaign and tribute. Each paid
  payment becomes one gift, with the payment's record ID as its external ID. See "Migrating
  from NPSP" in the admin guide.
- **Split gifts are refused, not half loaded.** A gift designated to several funds arrives as
  one line per designation; each line is rejected in the dry run until the lines are combined
  into one row, so no gift is loaded to one fund only.
- **Already using the Import tab?** Health Check finds the new mappings missing, and **Restore
  import templates** adds them. Your own mappings are not touched.

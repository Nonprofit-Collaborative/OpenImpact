# Release note line: merging and splitting households (draft for v0.1)

Written for Maria, per plan Section 7.4. This line is assembled into the public v0.1
release notes; it is not the iteration report.

- **Fix a duplicate family in a minute, from the record page.** Open a household, click
  "Merge or split", find the duplicate an import left behind, and see the two side by side:
  pick which name, greeting, primary contact, anniversary, and address survive, and everyone
  from both households ends up in one, with the giving history, letters, files, and notes
  coming across. The name and member count recalculate themselves unless you asked to keep
  your own wording. The same screen splits a person out into a new household or one you
  already have, renaming both. A merge cannot be undone, so the confirmation names both
  households before it runs.

# v0.1 draft release note: Access

One bullet, written for Maria, to be folded into the public v0.1 release notes.

- **Give a colleague access by name and role.** Nonprofit Settings now has an Access page.
  Pick a person, pick one of five roles (Nonprofit Admin, Fundraising Staff, Program
  Staff, Volunteer Coordinator, Read Only), and they have what they need. Each role shows
  who holds it, so you can answer "who can see our giving records?" in a few seconds, and
  removing access is one click. You never have to learn permission sets, and turning on a
  module later updates the roles for you. Creating the user and giving them a Salesforce
  license still happens in Setup, and the page links you straight there.
  See [Access](../admin-guide/access.md).

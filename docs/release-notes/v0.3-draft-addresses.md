# v0.3 draft release notes: Addresses (C-17)

Written for Maria, to be folded into `v0.3.md` at the end of the iteration (plan Sections
7.4 and 7.5).

- **Every address a household has, in one place.** A household, an organization, or one
  person can now have as many addresses on file as they really have: a home address, a work
  address, a winter address, and the address they moved out of last year. Nothing is
  overwritten when someone moves.
- **The address in use is copied to the standard address fields.** One address is marked the
  default, and Open Impact copies it into the standard address boxes, so mail merges,
  reports, letter templates, and any other app you use keep reading the address they have
  always read.
- **Nothing you already had is lost.** A household or organization created with an address
  already filled in keeps that address as its first address record, marked as the one in
  use.
- **You choose what a person's move means.** A new setting under Addresses in Nonprofit
  Settings decides what happens when someone edits one person's address: the whole household
  moves together, or that person gets an address of their own. Households moving together is
  the default, because a household usually shares a mailbox.
- **Seasonal addresses can be entered now.** An address can be marked Seasonal with the
  dates it is used, including a range that crosses New Year such as November 1 to March 31.
  Entering them now means they are ready for the automatic seasonal swap, which arrives in
  v0.4.
- **An Addresses tab, with the lists you actually want.** All Addresses, Addresses In Use,
  Seasonal Addresses, and Addresses Not Yet Verified.
- **Ready for an address verification app.** Every address carries a verification status and
  a last verified date that Open Impact never writes, so a verification app can fill them in
  and you can report on what has not been checked.

Read [the admin guide page](../admin-guide/addresses.md) for the five-minute walkthrough
with the Garcia household.

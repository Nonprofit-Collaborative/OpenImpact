# v0.4 draft release notes: The Giving nightly jobs can be switched on (G-07)

Written for Maria, to be folded into `v0.4.md` at the end of the iteration (plan Sections 7.4
and 7.5).

- **Payments now turn Overdue on their own.** This is a fix, and it is worth reading twice: the
  three jobs that keep commitments moving overnight were built but nothing ever started them, so
  in a real org no recurring schedule was topped up and no payment was ever marked Overdue. The
  Overdue list view was permanently empty and the admin guide sent you to it anyway.
- **You switch them on from the app, not from Setup.** Nonprofit Settings, Giving, Nightly jobs,
  then Schedule the nightly jobs. One button starts all three: the installment top up at 1:15
  AM, the overdue pass at 1:45 AM, and the donor level pass at 3:00 AM. Stop the nightly jobs
  unschedules them again and changes nothing that has already been generated or marked.
- **The donor level pass moved from 2:15 AM to 3:00 AM.** It reads a giving total the rollups
  maintain, and the rollups start at 2:00 AM, so fifteen minutes was not long enough to call
  them settled. Nothing now shares an hour with the rollups or with the seasonal address swap at
  12:30 AM.
- **You can see that each job ran, and what it did.** The same page shows, for each of the three
  jobs, when it last finished and one sentence about the result, for example "Marked 4 payments
  Overdue" or "No payments were overdue". A job that has never run is blank, so you can tell a
  job that found nothing from a job that never started. An org that has not switched the jobs on
  is told exactly that, rather than warned about a run that was never going to happen.
- **Run the jobs now.** If you have just switched them on, you do not have to wait until
  tomorrow to see the Overdue list fill up. Donor levels keep their own Recalculate now button on
  the Donor Levels page.
- **A commitment that cannot be extended does not stop the rest.** Anything that fails goes to
  the Error Log and the run carries on, and the page tells you to look there when a job was due
  and recorded nothing.

Scheduling and stopping need the Manage Nonprofit Settings permission. Read
[the admin guide page](../admin-guide/commitments.md) for the walkthrough.

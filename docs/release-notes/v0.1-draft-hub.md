# v0.1 draft release notes: Nonprofit Hub and Nonprofit Settings

Draft lines for the v0.1 release note, written for Maria.

- **A home page that tells you what to do next.** The Nonprofit Hub opens on a setup
  checklist of eight steps, remembers which ones you have finished, warns you while
  automation is paused, and counts anything that has gone wrong so you can go and read it
  in plain language.
- **Every setting on one page.** Nonprofit Settings puts all of Open Impact's settings in
  one place, grouped into sections with a description under each one and a search box for
  when you remember the word but not the section. Changes take effect immediately and every
  one is recorded with the old value, the new value, who changed it, and when. Anyone can
  read the page; changing it needs the Manage Nonprofit Settings permission, and people
  without it are told so by name.

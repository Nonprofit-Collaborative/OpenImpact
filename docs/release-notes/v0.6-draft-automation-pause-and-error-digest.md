# v0.6 draft release notes: automation pause that ends itself, and the error digest

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Feature C-23,
in Core.

- **A pause ends by itself, and says so.** When a pause runs out, automation starts again at
  that moment and the list of recent changes records the end, with the time and the name of
  the person who paused. Every pause now shows a start and an end.
- **You can see who paused.** The Automation page names the person who paused and when
  automation comes back on.
- **Health Check catches a pause that will not end.** A pause left over from an earlier
  version, or set outside the Automation page, is now a warning with a link to the page where
  you resume it.
- **The error digest.** Switch it on in Nonprofit Settings, Error Log, and the people who look
  after Open Impact get one short email a day (or a week) counting the new Error Log entries by
  source and severity, with a link to each. It never copies what an entry says, it goes only
  to users of your own Salesforce, it does not use your daily email allowance, and when nothing
  is new it sends nothing.
- **A first save no longer switches features off.** On a new installation, pausing
  automation (or the first seasonal address run, or the first digest) before anyone had saved
  Nonprofit Settings stored reciprocal relationships and automatic households as switched off.
  Both now stay on, as shipped.
- **Health Check notices a digest that stopped.** If the digest is scheduled but has not run
  for two days, usually because the person who scheduled it left, Health Check says so.

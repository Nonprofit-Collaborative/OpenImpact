# v0.2 draft release note: Importing

One bullet, written for Maria, to be folded into the public v0.2 release notes.

- **Load a spreadsheet without a consultant.** There is a new **Import** tab. Pick what kind
  of file you have, upload your CSV, and Open Impact tells you what it thinks each column
  means, with the first few values from your file underneath so you can check it. Choose how
  a row should be matched against people you already have, with a plain sentence under each
  rule saying what it will and will not catch. Then run a **dry run**: it tells you exactly
  how many rows would be created, updated, matched, or rejected, and lists every rejected row
  with the reason, without writing anything. Fix the file, run it again, and commit when the
  preview looks right. The results screen says what actually happened, row by row, and you can
  download the rejected rows as a spreadsheet to fix and re-import. Every household, person,
  and organization an import creates is tagged with the import it came from, so months later
  you can still answer "where did these 400 households come from". This release loads people,
  households, and organizations; gift columns are recognized and kept with each row, and the
  Giving module loads them in a later release.

# v0.5 draft release notes: gift batches

Draft lines for the v0.5 release notes, written for Maria (plan Section 7.5). Feature G-17.

- **Type a stack of checks in one sitting.** A new **Gift Batches** tab in the Fundraising
  app. Start a batch with the deposit slip total, set the date, payment method, fund and
  appeal once, and type one line per check: donor, amount, check number.
- **It will not post until it balances.** The batch shows the deposit slip total, what you
  have typed, and in words how far apart they are. Posting is refused while they differ,
  and while any line is unfinished, with each problem shown beside its line.
- **One click makes ordinary gifts.** Posting turns every line into a gift, all or none, so
  households, funds, totals, receipts and acknowledgments work exactly as for a gift typed
  one at a time. Each line then links to the gift it became.
- **Posted means posted.** A posted batch cannot be posted twice, changed or added to. A
  mistake is corrected on the gift, by refund or write-off.
- **Nothing lost to an interruption.** Saved lines stay with the batch, so a half-typed
  stack can be picked up later from the **Open Batches** list.

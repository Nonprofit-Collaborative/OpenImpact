# G-02 integration notes

Feature: the packaged default giving rollup definitions.
Branch: `feature/g-02-default-giving-rollups`.

## Permission set entries

**None.** This branch adds thirty `Rollup_Definition_Default__mdt` records and nothing
else. Package shipped custom metadata is read by `RollupSelector` in system mode and is
never shown to a user, so it takes no permission set entry (the same reasoning as
`packages/core/integration/c-13.permissions.md`).

The two surfaces these records touch are already covered elsewhere and need nothing added
here:

- `Rollup_Definition__c`, the object the records are materialized into, is granted in
  `packages/core/integration/c-13.permissions.md`.
- The target fields these definitions write are shipped and granted by the features that
  own them: the twelve giving fields on Account and Contact
  (`g-01-g-04-g-05.permissions.md`), the fund and appeal totals
  (`g-03-g-06.permissions.md`), and the commitment and installment totals
  (`g-07-g-11.permissions.md`). Every one of them is read only to every permission set,
  because the rollup engine writes them in system mode and a value typed by hand is
  overwritten at the next calculation.

If a target field is granted to no one, the number is calculated correctly and simply is
not visible. That is a field level security gap in the owning feature, not a missing entry
here.
